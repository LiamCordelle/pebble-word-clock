# Changelog

## 1.0.1 — 22 October 2026

- First store release; includes native launcher and store icons.
- Pin published shared kit 2.1.0 and include verified face/detail screenshots.
- No artwork or runtime changes from the approved 1.0.0 review build.

## 1.0.0 — 22 October 2026

- Standalone Emery watchface using the shared-kit submodule and source links.
- Approved word grid preserved, with tap/flick health, weather, sun and NZ page.
- Classic/soft preamble, caption selection and light theme; common kit settings.
- Combined charging/disconnection and low-battery/disconnection captions.
- Next-day sun/zone labels and explicit unavailable sun events.
- System fonts only; launcher/store icons, screenshots, description and licences.
- 48 deterministic render scenes, prototype pixel checks, glance outputs and
  settings tests. Shared kit tested against Mondrian and Underground.

Initial local review build; superseded by the 1.0.1 release.
